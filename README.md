# 運動コミュニティ

## 概要
**確認済み**

運動コミュニティは、運動の報告・応援・ポイント・継続記録などを通じて、運動習慣の継続を支援するMVPです。

現段階では少人数での検証を中心に進めています。将来的な一般公開も視野に入れますが、まずはMVPとして安定して利用でき、価値や支払い意思を検証できる状態を目指します。

## 想定ユーザー
**要確認**

現在は、ゼミでの検証協力者とその家族など、少人数での利用を想定しています。一般公開時の対象ユーザーは今後の検証結果を踏まえて決定します。

## 現在の主な機能
**確認済み**

- 運動報告（日付・運動内容・時間・気分・コメント）
- 1日1回の運動報告制限
- 運動報告によるポイント獲得
- 連続運動日数の記録
- 3日・7日連続ボーナス
- ポイント履歴
- 運動履歴
- 応援メッセージ
- 1日2回までの応援ポイント
- ステッカーの購入・所持
- ステッカーによる応援
- 月額300円のプレミアムプラン案の表示
- 負荷（小・中・大）に応じた運動プランの試作表示

## AI運動プランについて
**確認済み**

現在の運動プラン提案は、本物のAIによる生成ではありません。JavaScriptにあらかじめ定義した固定プランを表示するMVPです。AIによる個別提案は将来機能として検討します。

## データ保存
**確認済み**

ポイント、連続記録、運動履歴、応援履歴、所持ステッカーなどの主要データは現在ブラウザの `localStorage` に保存しています。

Supabaseへの運動報告保存を追加していますが、現時点では正常保存できないケースが確認されており、調査中です。

## セットアップ・実行
**確認済み**

現在はビルド工程を必要としない静的Webアプリです。基本的な画面は `index.html` から動作します。

GitHub Pagesを利用して公開しています。

## テスト
**確認済み**

自動テストは現時点では導入されていません。主にブラウザ上で手動確認しています。

## 環境変数・外部サービス
**確認済み / 要確認**

SupabaseのURLとブラウザ向けpublishable keyを現在 `script.js` から利用しています。secret/service-role keyをフロントエンドへ置かないことを前提とします。

SupabaseのRLS（Row Level Security）とデータアクセス権限については、一般公開を見据えて今後確認・整理が必要です。

## 現在の主な課題
**確認済み / 要確認**

- Supabaseへの運動報告保存が正常に完了しないケースの原因調査
- localStorageとSupabaseの役割整理
- ユーザーごとのデータ分離・識別方法
- SupabaseのRLS・アクセス権限確認
- エラー処理とテストの整備
- ドキュメント整備
- 少人数でのMVP検証後、収益化・一般公開へ進む条件の整理

詳細は今後 `docs/current-status.md` に整理します。

## 開発方針
**確認済み**

今後は原則として次の流れで開発します。

1. GitHub Issueで課題を整理する
2. Issueに対応した作業ブランチを作る
3. 小さく意味のある単位でコミットする
4. 動作確認・テスト結果を記録する
5. Pull Requestを作成する
6. レビュー後にmainへマージする

AIを含む開発ルールの詳細は `AGENTS.md` に整理します。
